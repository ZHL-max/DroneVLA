# Demo 01: 最简单的VLA示例

## 概述

这个Demo演示了Vision-Language-Action (VLA) 的基本原理。

## 核心思想

```
输入：图像观测 + 自然语言指令
输出：机器人动作
```

## 架构

```
图像 → [视觉编码器] → 视觉特征
                              ↓
                         [多模态融合] → [动作解码器] → 动作
                              ↑
指令 → [语言编码器] → 语言特征
```

## 运行

```bash
cd demos/01_simple_vla
python simple_vla.py
```

## 学习要点

1. **视觉编码**：如何将图像转换为特征向量
2. **语言编码**：如何将自然语言指令编码
3. **多模态融合**：如何结合视觉和语言信息
4. **动作解码**：如何从融合特征生成动作
5. **模仿学习**：如何从专家演示中学习
