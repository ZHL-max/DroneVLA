# Demo 03: 扩散策略 (Diffusion Policy)

## 概述

这个Demo演示了扩散策略的核心思想：将动作生成建模为条件去噪过程。

## 核心思想

```
噪声 → [去噪网络] → 动作序列
           ↑
        观测条件
```

## 扩散过程

```
前向过程（训练）：
x_0 → x_1 → x_2 → ... → x_T (纯噪声)
  加噪    加噪    加噪

反向过程（推理）：
x_T → x_{T-1} → ... → x_1 → x_0 (动作)
  去噪      去噪          去噪
```

## 运行

```bash
cd demos/03_diffusion_policy
python diffusion_policy.py
```

## 学习要点

1. **扩散模型基础**：前向加噪和反向去噪
2. **条件生成**：以观测为条件生成动作
3. **多模态分布**：能捕获多种可能的动作
4. **动作序列**：预测未来多步动作，提高平滑性

## 与VLA的关系

扩散策略是现代VLA的重要组件：
- **UD-VLA** (ICLR'26): 统一扩散VLA
- **Cosmos Policy**: 视频模型的扩散策略
- **DreamZero**: 世界动作模型的零样本策略

## 优势

1. **多模态**：能表示多种可能的动作
2. **平滑**：生成的动作序列自然平滑
3. **稳定**：训练过程稳定
4. **灵活**：可以处理复杂的动作分布
