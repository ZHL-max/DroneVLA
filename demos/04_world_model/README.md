# Demo 04: 世界模型 (World Model)

## 概述

这个Demo演示了世界模型的核心思想：学习环境的动态模型，在想象中训练策略。

## 核心思想

```
真实环境                    世界模型（想象）
┌─────────┐                ┌─────────────────┐
│  s_t    │                │  s_t (初始状态)  │
│    ↓    │                │       ↓         │
│  a_t    │                │  a_t (策略)     │
│    ↓    │                │       ↓         │
│  s_{t+1}│                │  s_{t+1} (预测) │
│    ↓    │                │       ↓         │
│  r_t    │                │  r_t (预测)     │
└─────────┘                └─────────────────┘
  真实交互                     想象交互
  (昂贵、危险)                 (快速、安全)
```

## 架构

```
世界模型 = {
    动态模型: s' = f(s, a)     # 预测状态转移
    奖励模型: r = r(s, a)     # 预测奖励
    价值模型: V = V(s)        # 评估状态价值
}

策略训练流程：
1. 从真实数据学习世界模型
2. 在世界模型中想象轨迹
3. 使用想象的轨迹训练策略
4. 用策略收集新的真实数据
5. 重复步骤1-4
```

## 运行

```bash
cd demos/04_world_model
python world_model.py
```

## 学习要点

1. **动态模型**：学习状态转移函数
2. **奖励模型**：预测奖励信号
3. **价值模型**：评估状态价值
4. **想象训练**：在模型中训练策略
5. **模型预测控制(MPC)**：使用世界模型规划

## 与VLA的关系

世界模型是现代VLA的重要组成部分：

1. **世界模型作为策略**：
   - IDM策略：先预测未来视觉，再恢复动作
   - 统一VLA：世界建模作为训练目标

2. **世界模型作为模拟器**：
   - DayDreamer：在想象中训练机器人
   - WMPO：基于世界模型的策略优化

3. **世界模型用于生成**：
   - 生成训练数据
   - 预测未来视觉

## 应用到无人机

世界模型对无人机特别有价值：

1. **安全训练**：在想象中训练，避免真实飞行风险
2. **数据效率**：减少真实飞行数据需求
3. **长horizon规划**：预测未来多步状态
4. **风扰适应**：学习环境动态变化
