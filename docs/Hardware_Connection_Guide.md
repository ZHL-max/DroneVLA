### 1.2 相机连接方式

#### USB连接（推荐）

```
相机 ──USB 3.0──▶ 上位机 (Jetson/Raspberry Pi)
```

**优点**：即插即用、兼容性好、支持多种相机
**缺点**：USB线长度有限（建议<3m）

#### CSI连接（树莓派）

```
相机 ──CSI排线──▶ 树莓派 CSI接口
```

**优点**：低延迟、低CPU占用
**缺点**：仅支持特定相机

#### 网络连接（GigE/WiFi）

```
相机 ──以太网/WiFi──▶ 上位机
```

**优点**：距离远、多相机支持
**缺点**：延迟较高、带宽限制

### 3.2 上位机与飞控连接

#### 串口连接（推荐）

```
上位机 (Jetson)          飞控 (Pixhawk)
    │                        │
    │   ┌──────────────┐     │
    ├───┤  USB转TTL    ├─────┤
    │   │  (CP2102)    │     │
    │   └──────────────┘     │
    │                        │
    │   TX ──────────── RX   │
    │   RX ──────────── TX   │
    │   GND ─────────── GND  │
```

**连接步骤**：
1. 购买USB转TTL模块（CP2102或FT232）
2. 连接TX、RX、GND三根线
3. 配置串口参数：57600波特率，8N1

#### UART直连

```
Jetson GPIO              Pixhawk TELEM
    │                        │
    │   Pin 8 (TX) ─────── RX │
    │   Pin 10 (RX) ───── TX │
    │   Pin 6 (GND) ──── GND │
```

#### UDP连接（WiFi）

```
上位机 ──WiFi──▶ 地面站 ──UDP──▶ 飞控
```

**配置**：
```bash
# PX4配置
param set MAV_0_CONFIG = UDP
param set UDP_P0_IP = 192.168.1.100
```

### 3.3 MAVLink通信协议

MAVLink是无人机通信的标准协议，支持：
- 遥测数据（姿态、位置、速度）
- 命令（起飞、降落、航点）
- 参数配置
- 任务规划

### 4.2 线缆连接清单

| 连接 | 线缆类型 | 长度建议 | 注意事项 |
|------|----------|----------|----------|
| 相机→上位机 | USB 3.0 Type-C | 0.5-1m | 带屏蔽、固定牢固 |
| 上位机→飞控 | USB转TTL | 0.3m | TX/RX交叉连接 |
| GPS→飞控 | 6pin JST | 0.3m | 远离电调干扰 |
| 电调→飞控 | PWM线 | 0.2m | 按顺序连接 |
| 电池→电调 | XT60 | - | 注意极性 |

## 5. 数据传输流程

### 5.1 视觉数据流

```
相机 (30fps)
    │
    ▼
USB 3.0 (480Mbps)
    │
    ▼
上位机 (Jetson)
    │
    ├──▶ 图像预处理 (OpenCV)
    │
    ├──▶ VLA模型推理 (PyTorch)
    │
    ▼
动作指令 (4-DoF)
    │
    ▼
MAVLink发送
```

### 5.2 控制数据流

```
上位机
    │
    ▼
MAVLink消息
    │
    ├──▶ SET_POSITION_TARGET_LOCAL_NED (位置控制)
    ├──▶ SET_ATTITUDE_TARGET (姿态控制)
    └──▶ MANUAL_CONTROL (手动控制)
    │
    ▼
飞控 (Pixhawk)
    │
    ▼
PID控制器
    │
    ▼
PWM信号
    │
    ▼
电调/电机
```

### 5.3 遥测数据流

```
飞控
    │
    ▼
MAVLink消息
    │
    ├──▶ HEARTBEAT (心跳)
    ├──▶ ATTITUDE_QUATERNION (姿态)
    ├──▶ LOCAL_POSITION_NED (位置)
    ├──▶ GPS_RAW_INT (GPS)
    └─── SYS_STATUS (系统状态)
    │
    ▼
上位机
    │
    ├──▶ 状态监控
    ├──▶ 数据记录
    └──▶ 地面站显示
```

## 7. 故障排查

### 7.1 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 相机无法识别 | USB驱动问题 | 重新安装驱动、更换USB口 |
| 图像卡顿 | 带宽不足 | 降低分辨率、使用USB 3.0 |
| 通信中断 | 线缆松动 | 检查连接、加固线缆 |
| GPS无信号 | 天线遮挡 | 移至开阔处、检查天线 |
| 电调不响应 | 信号线接反 | 检查TX/RX连接 |
