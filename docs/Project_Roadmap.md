# DroneVLA 项目路线图
## 开发计划与里程碑

---

## 当前版本：v0.1.0 (2026-05)

### 已完成

- [x] 核心模型架构 (DroneVLA)
  - VisualEncoder (EfficientNet/ResNet)
  - LanguageEncoder (BERT)
  - StateEncoder (MLP)
  - WorldModel (GRU)
  - ActionDecoder (确定性/扩散)

- [x] 仿真环境 (PyBullet)
  - DroneEnv: 4种任务
  - DroneLanguageEnv: 语言指令支持

- [x] 训练基础设施
  - 数据集生成器
  - 训练脚本 (完整版/轻量版)
  - 评估脚本

- [x] 相机驱动
  - Intel RealSense
  - OAK-D
  - USB摄像头
  - Raspberry Pi Camera

- [x] 文档体系
  - VLA学习笔记
  - 世界模型综述
  - 多平台安装手册
  - 硬件连接方案
  - 数据集与训练指南
  - 真实部署指南

- [x] 演示项目
  - Demo 01: 最简单的VLA
  - Demo 02: CLIPort
  - Demo 03: 扩散策略
  - Demo 04: 世界模型

| 项目 | 优先级 | 说明 |
|------|--------|------|
| 测试覆盖 | 高 | 需要更多单元测试 |
