# 世界模型+VLA 综述总结
## World Model for Robot Learning: A Comprehensive Survey

> 基于论文 [arXiv:2605.00080](https://arxiv.org/abs/2605.00080) 整理
> NTU、UC Berkeley、Stanford、Oxford 联合研究

---

## 论文概述

这是首篇专门面向机器人VLA的世界模型系统综述，系统梳理了：
- 世界模型与机器人VLA融合的完整发展脉络
- 统一了领域核心定义、技术范式与架构分类体系
- 归纳了各类建模方法、典型任务场景与主流评测基准
- 深度剖析当前研究痛点与落地瓶颈

---

## 核心分类体系

### 三大功能角色

```
世界模型在机器人学习中的三大应用方式
│
├── 1. 做策略 (World Model as Policy)
│   ├── IDM策略：先预测未来视觉，再恢复动作
│   ├── 单骨干策略：联合建模视频和动作
│   ├── MoE策略：视频和动作专家分离交互
│   ├── 统一VLA：世界建模作为训练目标
│   └── 隐空间建模：JEPA风格的表征预测
│
├── 2. 做模拟器 (World Model as Simulator)
│   ├── 强化学习：在想象中训练策略
│   └── 策略评估：评分和排名候选行为
│
└── 3. 做生成 (World Model for Video Generation)
    ├── 交互式模拟器
    ├── 基于想象的策略学习
    └── 基础视频世界骨干
```

## 详细分类

### 1. 世界模型作为策略

#### 1.1 IDM风格策略

**核心流程**：先预测未来视觉轨迹，再用逆动力学模型恢复动作

**特点**：
- 解耦的"预测-执行"流水线
- 视频生成和动作恢复分离
- 灵活性高，可替换不同组件

**代表工作**：

| 工作 | 会议 | 核心创新 |
|------|------|----------|
| UniPi | NeurIPS'23 | 文本引导视频生成的通用策略 |
| GR-1 | ICLR'24 | 大规模视频生成预训练 |
| VidMan | NeurIPS'24 | 利用视频扩散模型的隐式动力学 |
| VPP | ICML'25 | 视频预测策略 |
| Gen2Act | CoRL'25 | 人类视频生成实现泛化操作 |
| Vidarc | arXiv'25.12 | 具身视频扩散模型的闭环控制 |

**3D感知IDM扩展**：
- AVDC (ICLR'24): 从无动作视频学习动作
- VidBot (CVPR'25): 从野外人类视频学习泛化3D动作
- NovaFlow (arXiv'26): 从生成视频的可操作流

#### 1.2 单骨干策略

**核心思想**：单一共享骨干通过联合扩散/预测同时建模视频和动作

**特点**：
- 统一的架构
- 端到端训练
- 更高效的推理

**代表工作**：

|------|------|------|
| UVA | RSS'25 | GitHub: ShuangLI59/unified_video_action |
| UWM | RSS'25 | GitHub: WEIRDLabUW/unified-world-model |
| VideoVLA | NeurIPS'25 | arXiv: 2512.06963 |

| Cosmos Policy | arXiv'26.01 | GitHub: NVlabs/cosmos-policy |
| DreamZero | arXiv'26.02 | GitHub: dreamzero0/dreamzero |

#### 1.3 MoE/MoT风格策略

**核心思想**：视频和动作专家保持分离，通过共享/交叉注意力融合交互

**特点**：
- 模块化设计
- 专业化分工
- 灵活的扩展性

**代表工作**：

| 工作 | 会议 | 核心创新 |
|------|------|----------|
| GE-Act | ICLR'26 | 并行流匹配动作专家 |
| Motus | arXiv'25.12 | 统一隐空间动作世界模型 |
| BagelVLA | arXiv'26.02 | 交错视觉-语言-动作生成 |
| FRAPPE | arXiv'26.02 | 通过未来表征对齐注入世界建模 |
| WoG | arXiv'26.02 | 条件空间中的世界建模 |
| STARRY | arXiv'26.04 | 时空动作中心世界建模 |

#### 1.4 统一VLA模型

**核心思想**：在单一多模态骨干中将世界建模内化为训练目标

**特点**：
- 端到端统一
- 知识共享
- 涌现能力

**代表工作**：

| 工作 | 会议 | 核心创新 |
|------|------|----------|
| GR-1 | ICLR'24 | 视频生成预训练 |

| InternVLA-A1 | arXiv'26.01 | 统一理解、生成和动作 |

**核心思想**：JEPA风格，在表征空间而非像素空间进行未来预测

**特点**：

- 避免像素级预测

## 关键洞察

### 1. 架构趋势
- 从解耦(IDM)到统一(单骨干)的演进
- MoE/MoT提供平衡的模块化方案
- 隐空间方法(JEPA)提高计算效率

### 2. 训练范式
- 大规模预训练 + 少样本微调
- 视频和动作的联合训练
- 世界模型和策略的闭环迭代

### 3. 数据需求
- 从专用数据集到大规模多embodiment数据
- 合成数据和世界模型生成的数据
- 少样本适应能力

### 4. 关键挑战
- 实时推理速度
- 跨场景泛化
- 安全性保障
- Sim2Real迁移

## 对无人机VLA的启示

### 可借鉴的架构

1. **IDM策略**：适合无人机的预测-执行模式
   - 先预测未来视觉轨迹
   - 再恢复飞行控制指令

2. **隐空间建模**：适合实时性要求高的无人机
   - 避免像素级预测的开销
   - 在表征空间快速推理

3. **世界模型模拟器**：适合无人机策略训练
   - 在安全的仿真环境中训练
   - 减少真实飞行的风险

### 需要解决的挑战

1. **实时性**：VLA模型推理速度 vs 无人机控制频率
2. **3D感知**：2D图像到3D空间的理解
3. **动态适应**：风扰、障碍物的实时响应
4. **安全保障**：预测和约束的结合
